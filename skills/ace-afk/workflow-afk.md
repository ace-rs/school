# ACE Workflow — Unattended

Use **Run the approved plan** (1–6) after `ace-afk/SKILL.md` steps 1–2 complete.

Read `ace/workflow.md`. Apply its six phases with these required unattended branches:

## **1. Orient**

Select the highest-priority unblocked task allowed by the approved goal. Record a mixed or
unexplained working tree as a blocker and stop the run.

## **2. Plan**

Resolve choices from the approved decision basis. Record the plan and validation in the
trail. Ask no questions after Go. Record a choice the basis cannot safely resolve as a
blocker and select another independent task only when no unresolved edits remain.

## **3. Implement**

Make the planned change within the operating envelope. Keep each slice bounded by the
approved goal and stop before any required boundary crossing. Use only delegation already
authorized in the plan and review each delegated result before accepting it.

## **4. Verify**

Retain decisive command results in the trail. Return a failed check to Implement. If it
cannot be repaired within the envelope, record the blocker and stop the run. Never leave
unresolved edits and select another task.

## **5. Audit**

Inspect the full diff against the approved task, envelope, specs, and loaded skills. Fix
every Violation, verify, and repeat the full audit until a fresh pass is clean.

## **6. Close**

Commit each coherent verified slice on the current branch only when repository
instructions authorize autonomous local commits. Otherwise retain the reviewed diff.
Never push, publish, release, deploy, or take another outward action. Update the trail
after every slice so interruption leaves recoverable evidence.

Continue with the next unblocked slice only when the working tree is clean after an
authorized commit. Stop when the approved plan is empty, every remaining slice has a
recorded blocker, the working tree contains a retained reviewed diff, the working tree is
unresolved, or verification cannot be repaired within the envelope. Then disarm the
heartbeat and write the handoff report required by `ace-afk/SKILL.md`.

Before recording a blocker, try to earn the missing input or use a faithful substitute
allowed by the envelope. Never weaken an acceptance criterion or fabricate a result.

Completion evidence is the final clean audit, verification results, close state, updated
trail, and the stop condition passed to `ace-afk/SKILL.md` step 4.
