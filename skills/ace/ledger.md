# Procedure evidence

Use this contract when a skill points here. Numbered steps run in order, including any
branch or Wait the procedure names. Do not print a marker for each step.

- Keep decisive evidence in the work: the relevant command result, changed file, plan,
  user authorization, or report.
- Quote the user's exact words when they authorize a gated action or settle a durable
  decision.
- Report verification and audit evidence before claiming completion.
- Record durable evidence in the target artifact when the conversation will not survive.
- If a prerequisite is missing, return to the earliest step that can establish it.

At a handoff or pause, state the decisive evidence and next phase in concise ordinary
prose.
